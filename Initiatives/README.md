# Initiatives

An initiative is owned, dated work with success criteria anyone can check. It sits between `Strategy/` (what we're choosing) and the skills, tasks and rollouts that get it done. If one rollout can finish it, it isn't an initiative.

Copy `_Template.md` to `<Title>.md`. Evergreen name, one file per initiative.

## Rules

- **Criteria are yes or no.** Someone can check each one and say true or false without a judgment call.
- **Check the criteria, not the status.** The status field is a claim; the criteria are the proof.
- **A person changes the status.** An agent can propose it.
- **Link, don't copy.** Point to meetings, decisions and working documents so the file stays current.
- **The Log only grows.** Add a dated line at the bottom.

## Statuses

`NEW` → `IN_PROGRESS` → `SUCCEEDED`. Also `PAUSED`, and `CANCELLED`, which keeps the file.
