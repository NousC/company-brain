# Rollouts

One page for each change that reaches other people or their agents: `YYYY-MM-DD Title.md`. Three sections:

- **Proposed:** what we want to change, for whom, and why.
- **Approved:** who approved what, and anything cut.
- **Applied:** what actually happened, and how to undo it.

Each rollout gets one line in `CHANGELOG.md`. The page holds the detail.

Git history is the snapshot here. For anything outside this repo, record the state before the change, because git won't hold it.
