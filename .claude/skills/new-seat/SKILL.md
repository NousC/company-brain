# New seat

1. **Confirm who's running this.** Only owners and admins add people.
2. **Learn the job:** what this person really does, what they own, and their GTM role.
3. **Invite them** in Settings → Team, with that role.
4. **Add them** to `People/Seats.md`.
5. **Preview what they'll get** with `assign { user }`. Their role brings skills and pins with it, so fill any gaps through `rollout`.
6. **Check it worked:** in Settings → Team, their agent shows as connected. Connect it signed in as themselves, never a shared login.
7. **Add a line** to `CHANGELOG.md`.
